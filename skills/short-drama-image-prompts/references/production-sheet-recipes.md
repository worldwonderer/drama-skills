# 生产资产图配方：角色三视图 / 场景方位图 / 物品白底图

来自对角色、场景、物品资产如何进入后续镜头的定性案例阅读，示例均为合成改写。
通用方法见 [common-recipe.md](common-recipe.md)；本文档提供可按项目调整的生产版式。
核心哲学：**先把"不变量"资产化，再让分镜只负责"变量"**——资产图在"影棚"里
定妆（纯白底、无情绪、无场景光），光影、构图、情绪全部留给分镜与合成环节
（IMG-03/IMG-04 的生产表述）。

## 一、角色三视图（写实参考配方）

版式恒定：**左 1/3 头肩肖像特写 + 右侧全身正/侧/背三视图并排，纯白底**。
描述段落顺序（写实风格版）：

```text
【风格标签】真实摄影, 电影级RAW原片, <角色名>,
包含角色完整的正面头肩肖像（头部及颈部完整可见，占画面左侧约三分之一），
全身正面、侧面、背面三视图, 并排排列,
<身份定位句>,                    ← 例：邪派宗主 / 培训机构校长
<年龄>+<身高>,                   ← 四十五岁身高一米八零（中文数字）
<身材比例与体型>,                 ← 服从角色设计，不统一套用审美比例
<发型>, <发色>,                  ← 两段分开：先形态后颜色
<目标模型确认过的风格/质量词>,     ← 不跨模型复制权重语法
<脸型+面部皮肤>,
<眼睛+瞳孔+眼神>,
<上装>, <下装>, <鞋>,             ← 严格从上到下，每件含颜色+款式+材质
<饰品/手持道具 或 "无饰品">,
纯白无缝背景(影棚级布光),
(画面极其纯净:1.5), (无文字:2.0), 无水印, 无图表, 无标注,
<布光方案>,                      ← 由结构、材质、气质与用途决定
摄影布光, 极致细节, 富士胶片感     ← 写实版固定收尾
```

符号规范：分隔"逗号+空格"；权重半角括号 `(超写实主义:1.5)`；负向约束写成正向
声明（"无水印, 无图表, 无标注"）；年龄身高中文数字、质量块阿拉伯数字。
角色图带生成引子：`创作一张三视图，背景是纯白的底色，以下是相关描述:` +
描述逐字。场景/物品无引子。

### 决策规则

- **布光按脸部结构、材质、气质与目标画风决定，不按性别二选一**：硬光可强调
  骨相、权力或粗粝材质；大面积柔光可强调肤质、亲和或轻盈服装。无论选择哪种，
  同一 Look 的识别锚点与参考图用途必须保持稳定。
- **磨损度写阶级**：穷=袖口磨损/膝盖补丁/鞋底磨薄；富=皮鞋锃亮；伪体面=廉价
  西装肩部微皱不合体+衬衫领口微黄+鞋面磨损。服装细节全部服务人设信息。
- **每个视觉细节归因身份**（IMG-02 的强化）：毒道宗主 → 毒蛇纹长袍+竖瞳+毒石
  戒指+紫葫芦+蟒皮靴，五个细节同一因果链。写不出因果链的细节删掉。
- **特殊状态开新资产**：同一人物的被俘/重伤等大状态直接固化进新三视图（"胸口
  与手臂有绳索捆绑勒痕"），不靠分镜合成硬改（对应 assets 层的 Look 变体决策）。
- **风格标签是项目级注入**：按项目风格前置 `【真人风格，写实风格】` /
  `【国漫风，二次元画风】` 等，设计稿本体不带标签。

### 范例（写实·反派宗主，合成改写）

> 【真人风格，写实风格】真实摄影, 电影级RAW原片, 万毒谷谷主, 包含角色完整的
> 正面头肩肖像（头部及颈部完整可见，占画面左侧约三分之一），全身正面、侧面、
> 背面三视图, 并排排列, 邪派金丹后期修士毒道宗主, 四十五岁身高一米八零,
> 九头身黄金比例, 极度修长的双腿, 头身比1:9, 高瘦阴鸷体型肩膀宽阔但身形消瘦,
> 灰白色长发披散至肩发丝干枯如枯草, 灰白偏绿发色, (超写实主义:1.5), 8k分辨率,
> 瘦削长脸颧骨高耸眼窝深陷面色青灰, 阴狠毒辣的暗绿色瞳孔竖瞳微现, 身穿暗紫色
> 华贵长袍袍面绣有毒蛇盘绕纹样领口高竖以暗金色扣环固定宽袖垂地, 下穿黑色绸裤
> 裤脚束入靴中, 脚穿深紫色蟒皮长靴靴面有鳞片纹理, 右手无名指戴一枚暗绿色毒石
> 戒指腰间挂一只紫色葫芦, 纯白无缝背景影棚级布光, (画面极其纯净:1.5),
> (无文字:2.0), 无水印, 无图表, 无标注, 硬光照明, 伦布朗光, 摄影布光, 极致细节,
> 富士胶片感

## 二、场景方位图（十一段式）

一个叙事空间可拆为 `场景名（东）/（南）/（西）/（北）` 多个独立资产，每个方向
的描述写"面朝该方向看到什么"。**做齐四向是高配做法**（正反打高频空间才需要），
常规空间做 1-2 个主方向即可。

```text
【风格标签】面向正<东|南|西|北>, 平视,
<风格定语>,                    ← 古代宫廷写实风格 / 现代都市家庭写实风格
<时间+光线>,                   ← 暖金色日光透过雕花窗棂洒入
<氛围>,
(no people:2.0), (uninhabited:2.0), empty scene,      ← 固定空场景块（英文）
(色调统一:1.5), (光影连续性:1.5), 电影级布光, 8k超高清,
<场景名（方向）>, <视角说明句>,
室内|室外,
中心为…, 地面为…,              ← 空间清点从中心和地面开始
<各方位物件>,                  ← 其余三向也交代掉
<天花板|天空>…                 ← 收在头顶
```

- **"中心→地面→四向→头顶"清点顺序**是多视角咬合的关键：任何一向的图自带
  其余三向的空间逻辑（IMG-04 的可操作化）。
- 好样本写明**光源来自身后方向**（面南图写"自然光从北面落地窗透入形成逆光"），
  这张南向图天然是北向图的反打。
- 方向卡也是**情绪面**：每张方向卡可携带各自的时间/光源/戏剧点（同一居所：
  南=时钟延时、西=晨光决心、东=月光悲伤），按剧情需要的情绪选方向。

## 三、物品白底图（八段式）

电商白底图语法，物品描述刻意比角色/场景短一半：

```text
【风格标签】真实摄影, 产品实拍, <物品名>,
<一句定义>,               ← 一块嵌入地面的巨大圆形封印石板直径约一米五
<材质>,                   ← 纯银材质表面有岁月氧化形成的淡灰色包浆
<工艺/结构细节×2-4句>,
<新旧磨损状态>,           ← 磨损状态承载叙事信息（新/旧/传世/凶器）
柔和布光, 纯白背景, 无杂物, (无文字:2.0), 无水印, 8k分辨率, 极致真实
```

物品默认用能看清结构与材质的克制布光；反光、半透明或剧情要求可改用其他方案。
颜色、材质与工艺是常用的辨识三元组，但具体字段以该物品的功能为准（IMG-05）。

## 四、首帧合成与定点修改指令

资产图合成分镜首帧的指令语法（图生链路，仍属提示词文本，不涉及调用）：

```text
画面比例与限制：人物的高度对比宏大的场景来看是非常小的，限制人在场景中的大小，
禁止出现人物过大的问题。视频画面禁止生成字幕和水印。
绝对人物站位：<角色A>站在画面右侧，面向右侧；<角色B>站在<角色A>左侧，面向右侧；
风格：真实风格，写实风格，照片风格,电影质感
环境描写: <一段>
镜头景别: 全景 (Full Shot)
```

要点：**逐人声明站位+朝向**；已知模型缺陷（人物过大、字幕）预防性写进指令。

增量修改用**定点手术句式**（IMG-06 的生产形态）：一句改动 + 显式冻结其余——

```text
画面中右侧的甲去掉，画面中不要出现甲，其他角色站位动作保持不变，其他内容保持不变。
```

多参考图用编号引用：`图一角色换上图二的衣服`、`五官参考图二图三，发型参考图一`。

## 五、资产范围决策（`craft_default`）

| 决策 | 判断方式 |
|---|---|
| 是否建角色资产 | 后续需要重复识别、绑定 Look、配音或保持连续时才建立。 |
| 是否拆 Location/View | 摄影方向会改变可见地理、入口、光源或叙事功能时拆分。 |
| 是否建物品资产 | 物品会被识别、持有、转手、损坏、读字或承担回扣时建立。 |
| 描述写多长 | 写到能稳定识别与执行即可；删除不能归因身份、结构、状态或用途的装饰。 |
| 一次覆盖多少集 | 先抽取完整已接受范围，再按创作者停靠点接受；不从固定资产数量倒推剧情。 |

## 六、质量判据与反模式

判据：每个视觉细节能否归因身份（因果链检验）；资产是否只写不变量（场景光/
情绪进白底定妆图=返工高发原因）；物品三元组齐全；场景能否咬合正反打（光源
方向声明）；描述内角色名与资产名一致。

反模式（定性案例中的返工机制）：

1. 白底定妆图写场景氛围光（"卧室暖黄烛光氛围"→连续重生成不确认）。
2. 表单字段直贴描述（"身份:女配\n年龄身高:20岁"）。
3. 一句话资产（12 字的"风筝"描述）。
4. 无语义命名（资产名叫 '1'、'站位'、'参考'——下游无法按名索引）。
5. 不改描述的纯抽卡重试（同描述连提 3 次，无迭代）。
6. 描述内角色名与资产登记名不一致（写 A 名生成 B 人）。
