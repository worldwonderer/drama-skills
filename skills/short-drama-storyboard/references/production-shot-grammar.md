# 生产分镜工艺：把"拍"翻译成可执行的时间脚本

来自对剧本拍、分镜、关键帧与视频提示词如何衔接的定性案例阅读，示例均为合成改写。
方法论见 [shot-craft.md](shot-craft.md) 与 [keyframe-craft.md](keyframe-craft.md)；
本文档是生产端的翻译规则与决策词表。出现的数字只属于明确选择的项目 profile
（`craft_default`），不能凭偏离本身发出 finding。

核心认知：**分镜 prompt 不是画面描述，而是"在本镜所选时长内依次发生什么"的时间
脚本**——按时间顺序编排的微动作序列 + 一条有叙事动机的镜头运动。视频模型从
静帧起动，所以每镜编舞必须从静止姿态出发。

## 一、五个贯穿性思想

1. **一镜一职责**（SHT-03 的生产表述）：每镜有一个主导叙事职责。台词、反应与动作
   可同镜存在，只要 action budget 和注意顺序可执行；过载时按行动转向、听者后果或
   力学阶段拆镜，不按句号机械切镜。
2. **时间轴写作**：prompt 内部是时序链，不是静态构图。
3. **动作可测量**：给物理量——"幅度约10厘米""前倾约10度""静止约0.5秒"。
   量化让模型的动作幅度可控。
4. **运镜必须有动机**（SHT-04）：每镜收尾强制回答"为什么这样运镜"。
5. **连续性显式管理**：空间靠场景方位资产逐镜绑定；人物靠状态块逐镜续写
   （见 video-prompts 的生产提示词语法）。

## 二、编号与三层文本

- 分镜号 = `场序-镜序`。**场序按 clip 内"地点组"顺位**：换地点才递增，同地点的
  多个剧本场共用前缀；剧本自带集号时用三段式 `64-1-1`。
- 三层分工：原文切片（该镜覆盖的剧本原文）；一行中文镜头纲要（谁+做什么+镜头
  职能，供人工审阅索引）；完整时间脚本（喂给模型）。**纲要写差 = 人审索引
  失效**——"开场"两个字的纲要是真实事故案例。

## 三、拍→镜拆分规则

| 剧本形态 | 拆法 |
|---|---|
| 一拍 = 一句台词 + 一个动作 | 1 镜 |
| 一拍含多次行动转向或听者后果 | 按议程变化、反应职责与可执行语速拆镜；不使用固定句数/字数配额 |
| 一拍是爆发动作 | 拆"起势镜+发力镜"，两镜以武器/身体状态在切点咬合（起势镜结束在"剑刃露出三寸"的悬置点，发力镜从贯穿开始） |
| 一拍是纯反应/沉默 | 独立无台词镜，给最长静止时间（如汗珠滑落 2 秒静止跟踪） |

**建立镜头**：每个新地点组的第一镜做空间交代（全景/远景+人物站位），**剧本
没写也必须自增**；常以"过渡到下一镜的近景视角"显式勾连下一镜。

## 四、时序编舞语法（五连接词链）

单镜 prompt 骨架：

```text
<风格头>,首先<从静止状态起手的动作1>；接着<动作2>；随后<动作3>；
与此同时<并行微动态>；最终<收束姿态> 说：<台词>。<独立微动态句>。
镜头运动：<运镜描述>，叙事动机为<论证>。
```

- **"首先"必须从静止状态起手**——视频从分镜静帧起动，编舞起点=静帧姿态；
- **"最终"必须收在明确姿态**——动作有起止闭环，收束姿态就是下一镜的起点；
- **"与此同时"槽只放有来源的并行变化**：他人反应、环境压力或持续运动锚点可以
  帮助画面成立，但没有叙事/物理依据时宁可保持静止，不为满足配额发明微动态；
- 计时语法：`静止约0.5秒`、`保持约1秒后`；量化语法：`幅度约10-20厘米`、
  `前倾约10-15度`、`旋转约90度`、`前推1毫米`（武器微动）；
- 台词接法 ` 说：<台词>。`；无台词镜省略；
- 高潮段落可一滴汗写四个阶段：滑落→划过颧骨→下巴悬停→滴落。

**质量分水岭：删掉台词后，这条 prompt 在所选时长内还有可见的起点、变化和落点吗？**

## 五、镜头叙事学（运镜决策表）

| 戏剧情境 | 运镜 | 动机句范式 |
|---|---|---|
| 重磅台词/审判宣言 | 绝对静止镜 | "以静制动让指控信息完全落下" |
| 恐惧发酵/微表情 | 静止长镜跟踪细节 | "让微表情成为画面唯一焦点" |
| 心理崩溃 | Dolly Zoom | "表现内心世界的崩塌与现实的撕裂" |
| 混乱/失控 | 荷兰角 + 手持 | "匹配内心的混乱" |
| 彻底孤立/终局 | 上帝视角拉远 | "审判般的疏离感与彻底孤立的悲剧感" |
| 回避/心虚 | 缓慢横移 15 度改侧角 | "通过角度变化暗示回避心理" |
| 新势力入场 | 快速横摇/甩镜跟随 | "以快速运动引入新的对抗力量" |
| 爆发动作 | 快速跟摇/环绕 90 度 | "强化战斗的流畅感与力量感" |
| 权力关系 | 俯仰角编码：俯拍被审者、仰拍威严/狼狈 | "从俯视的审判视角过渡到平视接收其辩解" |

景别递进：场内遵循**全→中→近→特写**收紧曲线，情绪顶点上大特写/极端特写
（剑尖、眼部），**顶点后拉远收场**（上帝视角/全景）是标准收势。正反打用过肩/
越肩镜承接，遵守 180 度轴线。

Dolly Zoom / 荷兰角 / 甩镜是点睛手段；只有视角、失衡或注意力突然改变时才使用。
重复使用会让每个节点失去差异，但不能靠固定次数判断（SHT-07）。

## 六、场景戏型分解模板

- **对峙戏**：建立镜（全景+站位）→ 攻方低角仰拍推近 → 守方正面中景推近 →
  静止近景接收指控 → 高角俯拍辩解者→降至平视 → 新势力甩镜入场 → 武器/道具
  极端特写静止 → 恐惧微表情静止长镜 → 崩溃特型运镜 → 上帝视角拉远收场。
- **动作戏**：扑击起势镜（快速横摇跟随轨迹）→ 发力结果镜（环绕跟随旋转斩击）→
  伤害具体化特写 → 强者冷收静止镜。
- **情绪戏**：细节大特写起（手指痉挛）→ 缓慢上移至面部 → 反应镜（俯身抓手）→
  特写摩挲+上摇到脸 → 决心近景 → 低角仰拍逆光收（脊椎一节节挺直，配角化为剪影）。

## 七、项目 Profile 决策（`craft_default`）

| 决策 | 如何确定 |
|---|---|
| 拍如何拆镜 | 由动作边界、反应职责、空间变化与可执行时长共同决定，不追求固定比值。 |
| 台词如何分配 | 先保证一次可表演语气与口型负载；过长时按行动转向拆分，而非机械按字数。 |
| 单镜还是分镜组 | 先作者化独立 shots，再按目标生成方式编组；编组不改变 shot 身份。 |
| 子镜密度 | 爽点可更紧，情感处理可更松，但每次切换都要有注意、压力或状态理由。 |
| 单元时长 | 从必须保留的动作、反应、对白与落点反推；放不下就删减、拆镜或请求改边界。 |

## 八、反应职责（SHT-11）

对白覆盖存在不等于后果被接收。关键信息改变听者的权力、关系、知识或选择时，必须
在本镜或后续独立镜中给出可见处理与落点；景别、时长和是否切镜由后果重量、表演动作
及项目节奏决定。群像可用全场与个体两级反应，但这只是表现选项，不是固定组合。

## 九、自检清单（每镜逐条过）

1. 删掉台词后，在所选时长内仍能看见有起止的表演或物理变化吗？
2. 动作有起点姿态和终点姿态闭环吗？（"首先从…状态开始 / 最终保持…姿态"）
3. 运镜句能回答"为什么这样运镜"吗？
4. 并行微动态有 source/环境依据吗？没有时是否避免为“画面活”而硬加？
5. 情绪有方向性弧线吗？全程恒值是失败；回落合法（崩溃后泄力、劝服后回稳）。
6. 新地点第一镜交代空间与站位了吗？
7. 台词与反应在所选时长/语速内可执行吗？对照剧本是否遗漏或改变相对动作顺序？
8. 镜头数量能由 coverage、动作边界、反应职责和时长解释吗？
9. 每镜人物站位与上一镜衔接吗？（位置漂移是高频退回原因）
10. 手部与持物能否逐步执行？放下、换手、双手动作、递交/取回是否有可见来源？
11. source exact-readable 字段是否有承载面与 treatment，且没有被通用 no-text 覆盖？

## 十、范例（合成改写）

### 建立镜头（剧本没写、分镜自增）

```text
真人电影风格,首先镜头从高处俯瞰全景静止约0.5秒展示街道全貌；接着缓慢向下推近
同时略微向画面中左平移；随后聚焦于两人的对峙区域；与此同时围观人群中有轻微骚动
数人交头接耳；最终镜头稳定在中全景位置。碎茶碗旁有茶水缓慢沿石板缝隙流淌。
镜头运动：从高角度全景缓慢推近至中全景，揭示冲突核心区域，叙事动机为建立空间
关系后引导观众聚焦矛盾。
```

### 动作戏两镜拆解（起势镜 + 发力镜，以武器状态咬合）

```text
真人电影风格,首先前景魔物从岩石后猛然跃起利爪前伸扑向修士甲；接着修士甲双眼
猛然睁大身体本能后仰右手开始从剑鞘中抽剑；随后另外两只魔物同时从背景跃出形成
夹击之势；最终修士甲的剑刃刚刚露出剑鞘三寸寒光一闪。镜头运动：快速横摇跟随
魔物扑击轨迹，制造紧迫的攻击节奏感。
```

```text
真人电影风格,首先修士甲的剑刃贯穿第一只魔物魔物化为黑烟消散；接着借横斩余势
身体顺时针旋转剑锋划出弧线；随后旋转中斩过第二只扑来的魔物；与此同时第三只
魔物扑至近前；最终反手一剑刺穿第三只魔物剑尖从其背部穿出。镜头运动：环绕修士
甲约90度跟随旋转斩击，强化战斗的流畅感与力量感。
```

### 静止顶点两连镜（压迫 → 恐惧发酵）

```text
真人电影风格,首先剑尖在其咽喉前1厘米处微微颤动显示持剑者的力量控制；接着其
喉结因吞咽上下滚动一次；随后剑身冷光因微颤而闪烁；与此同时颈部皮肤因紧张起
鸡皮疙瘩；最终剑尖稳定不动形成死寂般的静止 说：你是不是忘了你现在的状况。
镜头运动：极端特写保持静止约1.5秒，叙事动机为以绝对静止强化生死一线的紧张。
```

### 反例（勿模仿：空壳镜）

```text
真人电影风格,某人身体后仰靠在椅背上，轻松地说话。镜头保持静止。
```

（无时序、无量化、无微动态、无动机——删掉台词后只剩一个静态姿势。）

## 十一、反模式

1. 旁白切片当分镜（小说旁白按逗号切进纲要，prompt 全是"嘴唇开合说话"空壳）。
2. 资产管理名泄漏进画面文本（占位文件名出现在 prompt 正文里）。
3. 图片引用标记侵入台词内文。
4. 无动机运镜（"镜头静止。"单独出现不解释）。
5. 台词标点+句式句号叠加（"血口喷人！。"——收尾句号只加在无标点台词后）。
6. 负面约束堆砌淹没内容（防缺陷补丁头尾重复 150+ 字，正文动作被稀释——补丁
   只在目标模型确有该缺陷时使用）。
