# 生产视频提示词语法：成片层语法、连续性系统与模型适配

来自对剧本、分镜边界、参考帧与视频任务之间完整链路的定性案例阅读，示例均为合成
改写。本套件的 motion spec 方法见 [motion-recipe.md](motion-recipe.md)；本文档是
生产端语法的对照参考：写 generic prompt 时借用其成熟约定，但套件产物仍以 motion
spec 七部分为权威结构，且**不调用任何生成服务、不出现供应商与模型产品名**——
模型相关规则一律写成"按目标模型确认"的条件规则。

核心认知：

1. **视频从静帧起动**：生成起点是分镜首帧图，所以每条 prompt 的动作编舞必须从
   "当前静止状态"出发，收在"明确的终止姿态"。
2. **模型不记得上一镜**：跨镜头一致性完全靠 prompt 显式携带状态。上一镜的结束
   状态逐字成为下一镜的开始状态（CON-01 的生产表述）——整套工艺最核心的连续性
   工程。
3. **指代必须可解析**：多人同镜或目标模型容易串角色时重复角色名并写物理成因；
   单人且指代无歧义时不把“禁代词”当普适 blocker。比喻若不能转成可见动作，再改写
   成物理表现。
4. **source 顺序不可重写**：台词发生在动作前、动作中还是动作后都属于故事语义；
   prompt 必须逐项核对台词相对动作的先后位置，不能只保留同一批内容。
5. **手部接触与道具 custody 必须可执行**：写清放下、换手、双手分离、递交、取回
   和画外持有；一只手不能同时握笔、分纸并操作另一件工具。
6. **文字策略先于通用禁字**：source/asset 声明的 exact-readable 字段必须保留并指定
   受控承载面；只有没有可读文字义务的镜头才能使用全局 no-text。

## 一、两代语法（按目标模型能力选用）

### A 型：单镜六件套（项目选择短镜 profile 时）

```text
<风格头>,画面描述: <按时间顺序的动作+拟声词+节奏，从静止状态起手>。
视觉重点：观众视线聚焦于<焦点>。
构图(Composition): <中心构图|三分构图|负空间构图|过肩…>。
景别(Shot Scale): <远景|全景|中景|近景|特写|大特写>。
机位(Camera Position): <正面|侧面|轴线后侧|正上方…>机位。
角度(Angle): <平视|仰拍|俯拍|上帝视角90度俯拍>。
镜头类型(Lens Type): <标准镜头|广角24mm|长焦…>。
光线(Light): <光源+方向+效果>。
【角色状态追踪】<逐角色状态块，见第二节>
```

画面描述带**拟声词和物理量**："右手猛地发力，'锵'一声清脆的剑鸣，长剑完全出鞘"。

### B 型：分镜组（项目选择容器式声画同出 profile 时）

```text
<风格头>,<按项目 profile 写声音策略；按 source text policy 写 no-text 或指定的
exact-readable/controlled-text 例外>；
c01,4s,(空间:<场景资产名+具体位置>)(姿态:<角色>(@图片N)-<姿态>; …)
(位置:<角色>-<相对方位>; …)(情绪:<角色>-<情绪词> <强度>/10)
<景别>，<时序动作+微动态+光线>。<角色>(@图片N)用中文<情绪副词>说道<台词>
c02,3s,(…) …
【文字策略】<无可读文字，或只允许列出的 exact-readable 字段>
```

- 子镜各带秒数，总和必须等于容器时长；子镜数量与容器时长来自已选择的项目 profile
  和 action budget，不把 15 秒或固定子镜数当通用默认；
- **四元组** `(空间:)(姿态:)(位置:)(情绪:N/10)` 置于每个子镜开头——空间锚定 +
  上一子镜终态显式续写；
- `@图片N` 资产引用：N 按 角色→物品→场景 顺延；**prompt 内每次出现角色名都挂
  引用**，但严禁侵入台词内文；
- 台词语法 `用中文<副词>说道<台词>`；长台词"停顿一拍后继续用中文说道<…>"
  二段化；声画同出模型一次生成台词+口型+音效，语速要求写进 prompt（"人物台词
  语速调整偏慢"）。

## 二、连续性系统（跨型通用）

### 角色状态块（A 型八字段，顺序固定）

```text
【角色状态追踪】<角色>-位置：<相对参照，如"街道中心偏西（与上一镜相同位置）">。
<角色>-姿态：<站立/蜷缩/弓步…>。<角色>-动作状态：<说话中/说完话/被拍得一个趔趄…>。
<角色>-朝向：<面向X/面向东…>。<角色>-手部状态：<右手持剑前指，左手捏剑诀…>。
<角色>-持有物品：<无（继承）/佩剑（斧头可能背在身后）…>。
<角色>-情绪状态：<词+可加强度>。<角色>-伤势状态：<无伤/颈部轻微出血…>。
```

扩展位（按需）：`服装状态`（换装连续性）、`头部朝向`（与身体朝向分离时）。

规则：

- **覆盖场上所有角色，包括本镜不入画者**；交互动作双方状态都记（拍肩者记手部
  落点，被拍者记"被拍得一个趔趄"）；
- 状态继承显式标注：`（继承）`、`（与上一镜相同位置）`；
- 动作状态记**进程**：说话中→说完话——相邻镜以此咬合；
- 持有物品含画外推断（"斧头可能背在身后"），防止道具凭空消失。

### 情绪强度弧线

`情绪:<词> N/10` 只在项目已选择数值表演 profile 时使用；没有该 profile 就写触发、
处理、选择与可见落点。跨镜变化应有方向与原因，平台整理和后果后的回落都合法，不按
固定档位或每镜增量评分。

### 空间连续

- 位置写**相对参照**（"病床右侧""右肩上"），不写绝对坐标；
- 场景资产用方位变体逐镜选用（`探视室（北）`/`篝火（近）`），正反打双方各绑
  各的背景资产防穿帮；
- 位移必须有过渡镜头，禁瞬移。
- 选择性**折叠、消失、替换**或形变必须写触发、目标范围、结束几何/状态和
  preserve set；非目标人物、道具、已批准文字承载面和空间锚点不能随邻近目标一起
  消失、复制或改形。一个 action budget 放不下变换路径和保留项核对时拆镜（VID-11）。

## 三、模型选型逻辑（一律泛称，不写产品名）

按本集主导戏型选"线"，同线内选最新代：

| 线 | 适用 |
|---|---|
| 声画同出全能线 | 项目已验证的分镜组容器（多人对白+叙事） |
| 质感线 | 唯美/静场戏 |
| 动作线 | 打戏密集集 |
| 表演线（旧代单镜） | 4-8s 单镜表演戏、微动作特写 |
| 后处理线 | 口型修正、字幕擦除兜底 |

## 四、参数配置

| 参数 | 规则 |
|---|---|
| duration | 从必须保留的动作、反应、对白与落点反推，并限制在目标模型已验证范围；若项目选择 15s/短镜等 profile，写入该 profile 而非宣称通用主力。 |
| aspectRatio | 竖屏短剧 9:16；横屏剧集/动漫 16:9（发行形态决定，全剧恒定） |
| amount | 由代表性试跑的可控性与预算决定；每次重投必须改变可解释变量并记录结果。 |
| resolution | 按目标模型、审片目的与交付规范选择草稿/量产/交付档，不把示例分辨率当跨项目规则。 |

运动幅度、特效等控制**全部写在 prompt 正文**，不依赖参数字段。

## 五、负面约束体系（防字幕/防串语言/防缺陷）

1. **无文字镜头的头部禁令**（项目确实没有 readable-text 义务时）：
   `画面不要出现任何文字`。若 source/asset 要求 exact-readable，改为列出唯一允许
   字段与受控承载面，禁止同时写全局 no-text。
2. **参考图准入**：头部禁令只约束生成意图，不能擦除参考图像素。人物、场景、道具
   或关键帧参考若带未批准标牌、界面、号码、水印、字幕或伪字，先**裁切、清理、
   遮罩或替换**；会破坏身份/地理/构图时退回 reference owner 决策。exact-readable
   镜头只允许批准的承载面和文字版本，不让旧字样从参考图回流。
3. **尾锁**：只复述已选择的文字策略；不能用`【不出现任何文字字幕】`抹掉证据文字。
4. **语言锁**（多语/出海）：`角色必须严格按照剧本台词的原始语言说话。画面中
   不得渲染任何可见字幕。`
5. **模型缺陷补丁**（条件启用，仅目标模型确有该缺陷时）：防双胞胎（多同类角色
   戏，首尾各写一遍利用注意力两端）、防人物过大（"限制人在场景中的大小"）。
6. **后处理兜底**：若本项目试跑证明 prompt 约束仍会漏出非授权文字，再启用擦除或
   受控文字层，并把失败样本与 preserve set 记入重试记录。
7. **模型专属负面词表是条件规则**：某些写实视频模型明令禁用"瞳孔反光/如鹰隼般/
   指节发白/咬牙切齿/僵立+说话"类抽象与生理细节词，而同样的词在其他模型上是
   高质量判据——写前必须确认目标模型，两套规则不可混用（VID-10）。

## 六、决策规则

1. **并发过载就拆**：当人物、道具、特效、可读文字与大动作无法在同一 action budget
   内各自落地时拆镜。并发上限由目标模型试验与项目 profile 记录，不从案例次数推成
   固定元素配额。
2. **台词密集镜单独成条**：台词戏与大动作戏不同条混装。
3. **反应职责**：权力、关系、信息或代价落到听者身上时必须给可见接收；是否独立成
   特写和停留多久由 consequence 与剪辑节奏决定，不按台词句数配额插镜。
4. **台词负载**：从所选时长、语速、表演动作和口型能力反推；放不下就删减、拆镜或
   请求 screenplay revision，不用固定字数替代试听。
5. **重试必须带迭代**：每次重投改一个变量（拆元素/补状态锚定/换措辞），禁止
   同 prompt 抽卡。
6. **预算来自本项目试跑**：不同风格与目标模型的失败模式会变；先用代表性镜头试跑，
   再按记录到的重试原因和区间排期，不移植无来源的通用成本比例。

## 七、范例（合成改写）

### A 型：六件套 + 状态追踪（拔剑镜）

```text
真人电影风格,画面描述: 镜头转向修士甲，听到命令，他脸上非但没有紧张，反而咧开
一个兴奋好战的笑容。他右手猛地发力，"锵"一声清脆的剑鸣，长剑完全出鞘。他手臂
前伸，闪着寒光的剑尖稳稳指向前方的魔物。视觉重点：观众视线聚焦于修士甲拔剑的
动作和脸上兴奋的笑容。构图(Composition): 过肩镜头，从修士甲背后看向魔物。
景别(Shot Scale): 中景。机位(Camera Position): 轴线后侧机位。角度(Angle): 平视。
镜头类型(Lens Type): 标准镜头。光线(Light): 剑身反射的寒光打亮了他的脸。
【角色状态追踪】修士甲-位置：队首前方。修士甲-姿态：站立，弓步。修士甲-动作
状态：拔剑指向魔物。修士甲-朝向：面向魔物（西）。修士甲-手部状态：右手持剑
前指，左手捏剑诀。修士甲-持有物品：佩剑。修士甲-服装状态：道袍完整。修士甲-
情绪状态：兴奋，战意高昂。修士甲-伤势状态：无伤。
```

### A 型：连续三镜的状态咬合（说话中→说完话→新角色入画交互）

```text
镜1【角色状态追踪】修士甲-动作状态：说话中。…修士甲-情绪状态：痛快，兴奋。
镜2【角色状态追踪】修士甲-动作状态：说完话。…修士甲-情绪状态：自信，骄傲。
镜3（虎妖甲入画拍肩）【角色状态追踪】虎妖甲-位置：修士甲身旁。虎妖甲-动作状态：
大笑并拍打修士甲肩膀。虎妖甲-手部状态：右手拍在修士甲肩上，左手叉腰。虎妖甲-
持有物品：无（斧头可能背在身后）。修士甲-姿态：站立不稳。修士甲-动作状态：被拍
得一个趔趄。修士甲-手部状态：双手下意识抬起保持平衡。修士甲-情绪状态：无奈，
但带着笑意。
```

### B 型：四元组状态接续（收尾镜，情绪低值也要标）

```text
真人电影风格,画面不要出现任何文字，生成视频无BGM；
(空间:居所阳台（南）(@图片3) 阳台)(姿态:女主(@图片2)-靠在男主(@图片1)肩上;
男主(@图片1)-站立望远)(位置:男主-阳台栏杆右侧; 女主-靠在男主右肩上)
(情绪:男主-平静 2/10, 女主-幸福 2/10) 远景，镜头继续缓缓后拉并微微上升，两人
靠在一起的身影越来越小，阳台、房屋、周围的建筑逐渐进入画面。远处天空湛蓝如洗，
几朵白云悠然飘过，整个画面沐浴在温暖的金色阳光中，一切归于宁静。
【不出现任何文字字幕】
```

## 八、自检清单

1. 每个子镜开头有四元组/状态块吗？上镜终态=本镜起点吗？
2. 场上所有角色（含不入画）都在状态块里吗？交互双方都记了吗？
3. 多人同镜的指代能唯一解析吗？比喻能转成目标模型可执行的物理表现吗？
4. 表演状态的变化或保持有触发与原因吗？回落是否承接了后果？
5. 文字策略与 source/asset 一致吗？exact-readable 是否被全局 no-text 误删？
   每张参考图是否也通过参考图准入，或已记录裁切、清理、遮罩或替换决定？
6. 并发元素是否都能在 action budget 内完成？若不能，拆镜或请求改边界了吗？
7. 台词、动作与反应能在所选时长和语速内完成吗？听者承担后果时有可见接收吗？
8. @图片引用齐全且未侵入台词吗？
9. 目标模型的专属负面词表核对过吗？
10. source 台词相对动作的先后位置逐项一致吗？重写有没有把“事前选择”变成事后解释？
11. 手部接触与道具 custody 可执行吗？放笔、换手、分离、递交和取回都有动作来源吗？
