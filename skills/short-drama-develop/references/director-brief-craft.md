# 导演阐述工艺：拆分/分镜前的项目级指令

来自对导演阐述如何约束完整生产链的定性案例阅读，示例均为合成改写。导演阐述是
整条流水线里高杠杆的人工输入：写在拆分/分镜之前，约束全剧所有下游生成——分镜
格式、运镜纪律、节奏曲线、按目标模型定制的禁用词。在本套件中，它落入
`short-drama.json#/creator_authority` 的 visual direction 与 production profile，
由本技能在项目规划阶段起草、创作者接受后生效；不替代各 owner 的产物权威。

## 开头范式（先锁身份，再锁忠实度，再展开规则）

```text
你将作为顶级<题材>短剧分镜师，为这部融合<A、B、C>核心元素的《剧名》生成专业
分镜脚本，必须100%严格忠实于原剧本，不得修改任何台词。
```

## 五种写法（按场景选用，可组合）

### 1. 可验收约束型（项目需要稳定规格时）

每条规则都应能对成片验收。以下数字只是某个合成项目的 house profile，不是通用
质量公式；新项目应按目标时长、生成方式与创作者选择重写：

```text
【铁律·不可违反】
1. 每集第1镜+场景切换第1镜=全景3.5秒含≥3个空间参照物；例外：梦境/闪回/幻觉/
   突袭/惊吓可跳过全景入镜
2. 第2镜=前3秒钩子（近景/特写+面部表情）；甜宠开篇/大结局用情绪特写替代冲突钩子
3. 同一人物全剧唯一资产绑定，禁换脸/换发型/换肤色；无换装时服装配饰100%一致
4. 上镜结束的手部位置+身体朝向+道具=下镜开始完全一致；位移须有过渡镜头，禁瞬移
5. 禁止添加剧本未提及的人物/动作/道具/场景元素
6. 每集末镜→悬念特写4秒→黑屏1秒；大结局可用圆满定格替代

【对话规范】
- 180度轴线遵守；竖屏过肩：前景肩部下1/3，后景面部上1/3
- 景别占比：双人全景10% / 单人中景25% / 近景40% / 特写20%
- 切换：说话人2-3s→反应2-3s；单人连续≤5s（独白≤15s除外）；长台词中切反应；
  提到第三方立即切其反应
- 反应优先：先给0.5-1s微表情，再切回说话人
```

可选 profile 维度包括色温/光比、留白、节奏停靠点、场景并发、反应职责和台词负载。
具体数值只能来自本项目试跑与创作者选择；台词负载从 action budget、语速与表演反推，
多人同镜只要求指代可唯一解析，比喻只在目标模型无法执行时改写为物理表现。

**服装/光影归属两大路线**（先选边再写规则）：**文字全锁**（服装光影逐镜写进
prompt）vs **参考图托管**（prompt 禁写服装/光影，以资产三视图为准）。选择依据
是三视图资产质量：资产精，托管省字数防冲突；资产粗糙，才用文字全锁。

### 2. 单集导演阐述型

写"本集在全剧的位置 + 三重叙事功能 + 分场镜头规划 + 节奏曲线（前段动、中段惊、
后段静、收尾动）"，适合关键集（首集/大结局/转折集）单独加写。

### 3. 风格速记型（多项目复用）

一两句话立规矩，全剧遵守：

- `镜头快速切换，剪辑节奏紧凑，高频切镜……禁止慢镜头，禁止停留式画面`
- `男频剧，拍摄以手持为主……光效以伦勃朗侧光、逆光为主`

### 4. 模型专属表演型（按目标视频模型定制）

针对特定视频模型的表演体系与禁用词表：

- 身份句升级为"资深院线电影导演 + 专业分镜师 + 目标模型提示词工程师"；
- **五维物理表演**：情绪禁用形容词，强制拆为 准备动作/面部微动作/肢体联动/
  重心变化 等可量化物理动作；
- **模型专属禁用词表**（合成示例）：某些写实视频模型明令禁止"瞳孔反光、如鹰隼
  般、瞬间、黑影、咬牙切齿、僵立+说话、指节发白"等抽象词与部分生理细节词；
- 打脸戏四阶段执行标准：铺垫嚣张镜→爆发快切→反派错愕特写+主角不屑特写→反派
  狼狈全景；
- 特殊视角设计入阐述层（"将镜头固定在轮胎上拍车内人物"）。

**关键教训：禁用词表是模型条件规则**。"指节发白/喉结滚动"类生理细节在多数模型
上是高质量判据，在个别模型上被明令禁止——写导演阐述必须知道目标模型，规则跟着
模型走，不能混用两套规则。

### 5. 阶段化跨集弧线型（长剧必备）

**跨集人物弧线与节奏弧线管理只活在这一层**（不在剧本层、不在资产层）。写法：
全剧分 3-4 阶段，每阶段绑定集区间+核心镜头语言+节奏目的：

```text
第三阶段：蓄力期（第17-26集）
核心镜头语言：短镜头快切、变焦、虚实切换、对峙畸变镜头。
节奏目的：节奏收紧，多线并行，悬念拉满。
```

再按集区间列表逐条绑定剧情节点（`#手持跟拍` `#平行蒙太奇` `#升格慢镜`），
结尾指明与第一集结尾相似构图的首尾呼应镜头。

## 反模式

1. **把剧本塞进导演阐述**（整集原文塞进指令字段）——指令与内容混流。
2. **空泛形容词**："画面高级有电影感"——无法验收。每条规则问一句：拿着成片
   能不能判定它被遵守了？
3. **规则打架**：不区分模型条件就同时写"要生理细节"与禁用词表。

## 拆分参数配套

- 按集拆分：明确本集局部戏剧结果、代价与 outgoing pressure；文字量从目标时长、
  台词语速、动作和停留空间反推。
- 按字数拆分容易切断场景目标、行动转向或反应职责；项目若仍选择该 profile，必须在
  切点复核场景与 handoff。需要可控生产语义时优先先剧本化再拆。

上述量化数值只是合成 house profile；只有创作者把它们选入当前项目后才成为验收约束。
"禁改台词""上镜终态=下镜起点"对应套件既有 invariant，不因写法流派而放松。
