## 1. 使用方式与规则分级

开发连续剧、从长篇材料切分短集、续写下一集，或人物与伏笔开始失去连续性时，
在 `story-craft.md` 和 `episode-design.md` 之外读取本文件。它补足人物纵向变化与
长线记忆，不规定固定集数、弧线形状或情节点比例。

- `structural_invariant`：已声明的角色、事实、铺垫、兑现与分集引用必须存在，或
  明确标为未解决；校验器只能处理这种可证明关系。
- `reviewed_invariant`：人物选择是否来自已有压力、单集是否产生局部结果、信息
  释放是否可信，需要独立审查者引用上下文判断。
- `craft_default`：前史储备、人物驱动力、双轨节奏和跨集记忆通常能减少空转；
  创作者可说明理由调整。
- `taste_option`：人物成长、倒退、停滞、悲剧化或拒绝改变都可成立，不能把“正向
  成长”设成质量门槛。

## 2. 先建前史储备，再选叙事切入窗口

故事第一页之前，人物已经形成习惯，关系已经积累债务，世界规则也已经留下后果。
开发者要知道这些前因，但观众不需要先听完人物小传。

### 2.1 前史储备

只储备能解释现在选择的过去：

- 哪次旧事让人物开始依赖当前策略；
- 哪个承诺、羞耻、损失或受益关系仍在约束他；
- 哪项旧事实让两个人对同一行为产生不同解释；
- 哪种世界规则已经在人物身上留下可见后果；
- 哪个过去形成的盲区会在当前压力下制造代价。

前史储备不是待塞进对白的资料库。每一项都标记：`writer_needs`（作者需要知道）、
`audience_needs_now`（观众此刻必须知道）或 `withhold`（暂时保留）。

### 2.2 叙事切入窗口

比较几个可能的切入时刻，选择满足以下问题最多的一处：

1. 压力已经启动，人物必须采取行动；
2. 人物的惯常策略眼下仍有效，却即将显出代价；
3. 观众能从一个行为、物件、关系动作或异常结果反推“之前发生过什么”；
4. 本集可以先完成一个局部行动，而不是只负责介绍世界；
5. 切得更早会变成准备工作，切得更晚会失去关键选择。

**`craft_default · STY-11`**：先建立与当前冲突有关的前史储备，再从旧策略开始付出
代价的时刻切入。只释放本场行动需要的证据，其余继续留在储备中。

开场安静或激烈都是 `taste_option`。钩子不是音量，而是观众能察觉的未闭合因果：
一个人为何提前锁门、一个熟人为何不用旧称呼、一个日常物件为何出现在错误位置。

## 3. 用人物驱动力预测选择

人物设定要能回答“压力变化后他会怎么做”，不只说明性格和外貌。为主要人物记录：

| 层 | 开发问题 |
|---|---|
| 意识到的追求 | 他现在明确想改变什么？ |
| 被保护的价值 | 即使追求失败，他仍不愿失去谁、什么身份或哪种自我看法？ |
| 被捍卫的信念 | 他用哪句偏颇但有来历的判断解释世界和自己？ |
| 前史成因 | 哪件旧事使这套信念与策略曾经合理？ |
| 惯常策略 | 他通常如何控制、讨好、试探、隐藏、交易、公开或撤退？ |
| 即时代价 | 这套策略正在伤害什么？ |
| 改变条件 | 哪个事实、关系后果或自主选择可能让旧策略失效？ |

“内在需要”不必等于道德正确答案。有人需要学会信任，有人需要承认自己想要权力，
有人最终拒绝改变。关键是行动、后果与选择能互相解释。

### 3.1 关系让驱动力相撞

同一场景中的双方分别写：

```text
A 想让 B 现在做什么：
A 不愿让 B 看见什么：
A 采取的策略与筹码：
B 想让 A 现在做什么：
B 不愿让 A 拿走什么：
B 的反制策略与筹码：
```

这样能把“关系很好/关系紧张”改写成当下可表演的压力。

## 4. 把人物变化写成可追踪的压力测试

人物弧线不是每集增加一个“成长点”，也不是性格标签从负面换成正面。记录每次真正
触碰旧策略的事件：

```text
进入策略 → 压力测试 → 仍按旧信念行动 / 尝试新行动 / 退回旧行动
→ 获得的局部结果 → 支付的代价 → 下一次更难的测试
```

**`reviewed_invariant · STY-12`**：若声称人物发生变化，审查者必须能指出压力测试、
人物选择、结果、代价与变化后的可见策略。只有台词宣称“我变了”或情绪强度改变，
不足以证明弧线移动。

以下都可以成立：

- **确认**：旧策略再次奏效，人物更相信它；
- **裂缝**：策略成功但代价第一次无法忽视；
- **试探**：人物短暂采用新策略，但保留退路；
- **回撤**：新策略失败，人物加倍依赖旧策略；
- **不可逆选择**：人物主动承担代价，使旧身份或关系无法恢复；
- **拒绝变化**：人物看见替代路径仍拒绝，走向悲剧或反弧线。

不要求每集都移动人物弧线。没有移动时，明确本集是在积累证据、加强信念、推进
外部目标，还是让配角/关系承担变化。

## 5. 每集必须产生局部戏剧结果

连续剧可以从上一集最后一秒接起，也可以在最危险的动作中切黑，但新一集不能只把
同一动作拖到下一个切点。每集至少完成一个可辨认的微型戏剧动作：

```text
当前目标 → 有能力的阻碍 → 人物选择 → 局部戏剧结果
→ 状态/代价改变 → 从结果中长出的下一股压力
```

局部戏剧结果不等于主角获胜。它可以是：

- 目标部分成功，但暴露了新的弱点；
- 目标失败，却拿到改变下一策略的证据；
- 人物误以为成功，观众看见代价已经启动；
- 人物主动放弃原目标，关系或道德位置因此改变；
- 对手成功封住路径，迫使主角换策。

**`reviewed_invariant · STY-13`**：集尾钩子之前，本集要让目标、阻碍或选择产生一个
局部结果。若删掉集尾黑屏后，本集没有任何已落地变化，只是在动作中间暂停，应修订
分集边界或补足结果。

集尾可以停在即将发生的动作，但悬念必须由本集结果造成。例如“门外有人”只是新
刺激；“主角为藏证据反锁门，门外的人却拿出她刚交出的钥匙”才承接了本集选择。

## 6. 管理信息权限与铺垫债务

“故事真相”“角色相信”“观众知道”是三套状态。维护最小信息权限表：

| fact_id | 世界事实 | 角色 A | 角色 B | 观众 | 当前可见证据 | 下一次改变权限的动作 |
|---|---|---|---|---|---|---|
| FACT-01 | 【填写】 | 知道/误信/未知 | 知道/误信/未知 | 明知/怀疑/未知 | 【填写】 | 【填写】 |

信息释放不是把答案说出来，而是改变某人可以采取的行动。揭示后追问：谁现在能质疑、
交易、逃跑、撒谎或公开？没有行动后果的信息可以延后、压缩或删除。

### 6.1 证据结论边界

可见载体出现后，分开三层记录：

1. `visible_carrier`：观众和人物实际看见/听见了什么；
2. `supported_claim`：该载体直接支持的最强结论；
3. `unresolved_inference`：仍可能成立、但现有载体没有证明的解释或责任归属。

例如，一台设备只对 `00:17` 作出反应，可以支持“设备识别 `00:17`”，却不能单独证明
“某个特定人物把记录改掉”。后者若仍影响行动，应保持 `suspected/unknown`，等待新的
独立载体，而不是因角色说得笃定就升级成 `known`。

**`reviewed_invariant · STY-15`**：信息权限升级必须与 `supported_claim` 相称；审查者
引用载体、直接结论和未决推断，阻止道具反应、巧合或单方陈述被扩写成其未证明的世界
事实。创作者可以选择角色误判，但要把角色信念与观众/世界权限分开记录。

铺垫是一笔债务，不是装饰：

- 首次出现要有当前场景的表面理由；
- 记录观众自然会怎样理解；
- 记录承诺回答的问题；
- 回扣时既回答旧问题，又改变当前选择；
- 改写铺垫后，标出受影响的分集、资产和镜头。

引用是否存在属于 `structural_invariant`；铺垫是否自然、回扣是否有力属于
`reviewed_invariant`。

## 7. 用双轨节奏安排张弛

双轨节奏分别记录：

- **外部压力**：事件密度、对抗强度、时间限制、空间风险；
- **内在情感负荷**：人物正在处理的损失、羞耻、希望、亲密、恐惧或道德冲突。

两轨可以同步，也可以错位：

- 外部高 / 情感高：爆发与不可逆选择；
- 外部高 / 情感低：熟练执行、冷静追逐、程序性危机；
- 外部低 / 情感高：等待、照料、隐瞒后的余震；
- 外部低 / 情感低：必要交接或呼吸，需控制篇幅并保留潜在压力。

**`craft_default · STY-14`**：分集与场景规划同时写外部压力和情感负荷，并说明与
上一单元相比为何升、降或错位。不要为了画出波浪而机械交替；节奏变化应来自人物
处理后果所需的时间。

呼吸不是无事发生。好的呼吸段会让人物重新解释刚才的事、尝试修复关系、隐藏代价、
处理伤势/道具/证据，或作出下一步选择。

## 8. 建立可恢复的跨集记忆

跨集记忆只保存后续决策所需内容，不复述全文。每集接受后更新：

1. **人物**：当前目标、策略、被测试的信念、选择、代价、物理状态；
2. **关系**：权力位置、信任/债务、未说出口的交易、最近一次越线；
3. **信息权限**：世界事实、各角色与观众知道/误信的差异；
4. **铺垫债务**：已埋未回、已改义、计划回扣、受影响位置；
5. **节奏方向**：上一集两轨落点与下一集需要承接/对比的原因；
6. **精确交接**：位置、动作、持物、伤势、时间、正在发生的决定或危险。

更新原则：

- 只写变化；未变化但下一集必须继承的事实进入精确交接；
- 已完成且不再影响后续的事件压成一句或移出活跃记忆；
- 伏笔、信息权限和未支付代价不能因摘要压缩而丢失；
- 新一集开写前先读活跃记忆，再读最近一集正文核对证据；
- 摘要与已接受正文冲突时，正文事实胜出，并修订摘要 owner。

## 9. 合成示例

以下仅演示方法，人物与事件均为合成。

> 一名夜班调度员长期私改末班车日志，替临时司机掩盖迟到。她相信“只要我把记录
> 做平，所有人就能保住工作”。某夜，一辆早已注销的旧车按她伪造的时间驶入总站。

### 前史储备与切入

- 储备：她曾因如实上报导致搭档被解雇，因此开始保护性改表；这是作者需要知道的
  前史，不在开场解释。
- 切入：她正把最后一处时间改平，打印机却吐出一张不存在于系统的到站单。旧策略
  仍在执行，代价已经进入同一画面。
- 释放：磨损的旧工牌与她下意识遮住日志的动作先给证据；搭档旧事暂时保留。

### 第一集局部动作

- 目标：在交班员进门前销毁异常到站单；
- 阻碍：到站单每撕下一角，旧车广播就准确报出她的位置；
- 选择：她不再销毁，而是把纸压进当晚真实日志并签上自己的名字；
- 局部戏剧结果：异常记录获得了一个可追责的现实入口，她也失去“只是系统错误”的
  退路；
- 下一压力：交班员刷卡进门，手里拿着那名被解雇搭档的旧工牌。

### 人物与双轨节奏

- 人物进展：旧策略“替别人隐藏”第一次变成“用自己的名字承担”；这只是裂缝，
  不是完成成长；
- 外部压力：由低到高（改表→异常单→广播定位→交班员进门）；
- 情感负荷：前段被压低，签名时升高，集尾旧工牌让过去的代价重新进入现在。

## 10. 失败征兆与审查问题

### 失败征兆

- 人物小传被整段塞进首集 VO/对白；
- 开场从世界起源讲起，当前人物还没有必须完成的动作；
- 角色弧线只写“从自私到无私”，没有压力测试、选择与代价；
- 为保证每集有反转，人物无证据地反复改变立场；
- 集尾停在动作半途，而整集没有局部结果；
- 所有铺垫只为解释答案，不改变任何人的下一动作；
- “情感戏”只有慢镜与哭泣，没有人物处理后果；
- 跨集摘要很长，却遗漏谁知道真相、谁持有证据或哪笔铺垫未回；
- 一个道具只证明时间/地点/状态，却被角色或摘要直接升级成作案者、动机或完整机制；
- 固定比例、集数配额或节奏图被当成普遍阻断规则。

### 独立审查问题

1. 开场哪个可见证据说明世界此前已运行？哪些前史被正确保留而没有倾倒？
2. 为什么选择这个叙事切入窗口；更早或更晚会损失哪个选择？
3. 人物的追求、被保护价值、被捍卫信念与惯常策略怎样产生当前行动？
4. 若人物发生变化，压力测试、选择、局部结果与代价分别在哪里？
5. 本集在集尾钩子之前完成了哪个局部戏剧结果？
6. 新信息改变了谁的行动权限，而不只是让观众听到解释？
7. 外部压力与情感负荷为何同步或错位；呼吸段处理了什么后果？
8. 跨集记忆能否恢复人物、关系、信息、铺垫、节奏和精确交接？
9. 每个 visible carrier 直接支持什么结论？哪些责任归属或机制解释仍必须保持未决？
