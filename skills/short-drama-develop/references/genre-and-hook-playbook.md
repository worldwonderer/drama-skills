# 题材条件与钩子手册

这份参考资料来自对不同题材完整“剧本—资产—分镜—提示词修订”链的定性阅读。
它只保留可以用在新项目里的故事推进方法和常见问题，不保留项目名、原台词、内部 ID、原提示词、媒体
地址、供应商字段或题材频次。这里没有热度排名，也没有按标签自动套用的剧情公式。

本手册负责**跨题材的比较**：同一条轴线上，不同题材怎样分岔。单个题材的执行细节
（场面颗粒、集尾钩子取向、前中后期打法、该题材特有的制作成本）拆在
[genre-cards.md](genre-cards.md) 索引下的题材卡里，一次只读一张。
两层的分工是：先用本手册确认压力机制选对了，再用题材卡校准这个题材更常用的落点。

## 使用方式：先看故事怎么运转，不先认标签

题材标签只用来帮助找到可能相关的写法。真正要选择的是：

1. **压力从哪里来**：规则、关系、证据、制度、空间、资源还是身体限制；
2. **人物怎么应对**：主角靠隐藏、照料、专业能力、权威、交易、逃避还是冒险解决问题；
3. **观众每集看到什么结果**：真相、关系、权力、路线、身份或生存条件怎样变化；
4. **谁知道什么**：谁知道、误信、怀疑，谁能把事情说出来或公开；
5. **观众具体看到什么**：哪个行为、物件、空间变化或群体动作能证明结果成立；
6. **制作难点**：哪些造型/状态、场景/方位、道具/状态、群体区域、必须照抄的文字或
   镜头起止状态需要持续追踪。

同一“悬疑”可以由空间规则、关系谎言或技术证据驱动；同一“爱情”可以走互助、权力
不对等或身份冲突。只有故事推进方式和当前条件相符时才借用下文；不相符就回到
[story-craft.md](story-craft.md) 重新想清故事怎样持续推进。

## 不同题材怎么推进

这张表比较的是**轴线上的差异**，不是各题材的完整写法。选定方向后，到最后一列的题材卡里
取该题材的场面颗粒、钩子取向、前中后期打法和特有成本。

| 题材方向 | 压力怎样持续 | 每段先给什么结果 | 制作时必须拍清什么 | 常见问题 | 题材卡 |
|---|---|---|---|---|---|
| 悬疑 / 规则恐怖 / 生存 | 安全规则逐步失效，可走的路、可用的时间和保护手段越来越少 | 查明一条能决定下一步的新事实，同时失去一条退路 | 门槛、路线、计时、有明确用途的关键道具、感官异常与受限身体状态 | 只把黑暗、噪声和形容词变强；旁白替代可见验证 | [悬疑规则](genre-cards/悬疑规则.md) |
| 家庭 / 照料 / 关系伦理 | 私人义务与自我保护互相冲突，经济/照料/名誉筹码可执行 | 关系边界、证据归属或公开地位改变 | 往复照料动作、便携证据、见证人分区、退出路径 | 群体重复谴责，人物没有新选择或执行能力 | [家庭关系](genre-cards/家庭关系.md) |
| 古装 / 奇幻 / 婚恋 / 隐藏身份 | 礼制、阶序、阵营与公开选择限制关系 | 行为让隐藏地位或联盟获得新的公开解释 | 造型、随行层级、身份道具、入场方式、空间区域与知情者反应 | 奢华/寒酸形容词堆叠；突然报身份代替此前证据 | [古装权谋](genre-cards/古装权谋.md) / [仙侠修真](genre-cards/仙侠修真.md) / [豪门婚恋](genre-cards/豪门婚恋.md) |
| 职场 / 技术 / 轻喜剧 | 一个日常工作疏漏造成越来越具体的后果 | 别人能当场核对的修复结果，随后角色地位改变 | 必须照抄的技术名称、操作顺序、核对点、屏幕/设备状态与见证更新 | 同事先夸“天才”；通用屏幕特写；人人同一惊讶反应 | [职场喜剧](genre-cards/职场喜剧.md) |
| 复仇 / 权力反转 | 对手拥有真实手段，主角以证据、联盟或能力改变实际权力 | 一项旧权力失效并产生后果，而非只获得口头认可 | 证据链、公开场合、对手反制、受影响者的反应与代价 | 重复受辱—亮牌；身份揭示不改变任何人的行动空间 | [复仇打脸](genre-cards/复仇打脸.md) |
| 动作 / 任务 / 冒险 | 地理、资源、时间与对手学习共同收窄可行路径 | 完成一个阶段目标并留下伤势、损耗、暴露或路线变化 | 轴线、出入口、距离、持物、能力边界、伤势与交接 | 动作更大但任务状态不变；同一镜承担过多力学阶段 | [动作任务](genre-cards/动作任务.md) |
| 身份错位 / 身体互换喜剧 | 外部任务迫使人物用不合身的身份、身体或权限解决现实问题 | 任务状态先改变，再让身份误读带来关系或地位余波 | 当前身份占用、别人如何识别、身体能力边界与多主体位置 | 设定梗不断重复，任务和人物策略没有进展 | [身份错位](genre-cards/身份错位.md) |
| 生活流 / 小人物 / 都市温情 | 一个具体小目标被来客、误会、匮乏或照料义务打断 | 小事被实际完成、放弃或重新理解，关系留下轻微但可见变化 | 日常物件、距离、手部选择、环境节奏与留白 | 套用真人爽剧的密集大特写和公开翻盘，压扁生活质地 | [生活流](genre-cards/生活流.md) |

这张表只是提问清单，不是题材判定器。混合题材可以把几种做法放在一起，但要说清
主要矛盾是什么、观众先看到哪个结果，以及制作要求会不会互相打架。

题材卡同样不是判定器：它是可被创作者一句话覆盖的 `craft_default`，一次只读一张，
跨题材时主卡读全、辅卡只摘一两条。召回规范与冲突优先级见 [genre-cards.md](genre-cards.md)。
本手册下文的各题材小节保留跨题材共用的因果链与失败征兆；具体到某一部戏怎么落，以卡片为准。

## 悬疑与规则恐怖：每过一道险关，都要有实质变化

规则恐怖不是不断宣读更多规则。每过一道安全线，都要让局面真的变掉：

```text
暂时安全的状态
→ 计时、封闭空间或逃生路线出现能被人物验证的小破口
→ 人物试探并得到局部发现
→ 空间、身体或保护手段受到无法马上恢复的限制
→ 旧策略失效，下一步只能承担更高代价
```

条件化做法：

- 先让保护行为真的改变行动条件，例如堵住入口、交出唯一光源、限制移动，而不是只给
  关系温情；
- 每过一道险关，先让人物和观众看清一种新变化，避免怪物、变形、解释、群体
  反应和摄影花样同时争夺注意；
- 完整揭示前，可先让失败者、受损物或失效路径证明威胁会造成什么；
- 有明确用途的关键道具从取得、未启用、触发、画面可见的启用状态、可用次数/进度、
  代价到恢复，保持前后一致，
  具体记录见 [prop-and-state.md](../../short-drama-assets/references/prop-and-state.md)；
- 下集压力可以停在安全距离被突破、救援路线被封，但本集必须先完成发现、
  试验结果或路线变化，不能只在惊吓前切黑。

失败时先问“这次过关后，谁能做什么、不能做什么”，而不是再加阴影、尖叫或规则 VO。

## 家庭与关系戏：从照料推进到证据和公开后果

家庭戏的强度不来自更响的责骂，而来自私下发生的事带来真实后果。一个可调整
的因果链是：

```text
互相照料或共同承受匮乏，让双方彼此有了牵挂和亏欠
→ 私人排斥/伤害留下可携带证据
→ 受影响者作出自我保护选择
→ 证据进入有人能作出决定或采取行动的公开场合
→ 不同见证者各自获得一条新事实并改变行动
→ 退出、保护、作证、让路或约束真正改变权力
```

- 预示未来结果再回到决定性选择，只在同一关系/物件锚点能让两段互相解释时使用；
  不是所有家庭戏都需要倒叙；
- 群体反应按“能做什么”分区：知情者、能作决定的人、利益相关者、旁观者。每组只在
  新事实改变其行动时反应，不能用一圈惊叹代替实际后果；
- 照料既可以证明爱，也可以成为控制手段；保留双方各自的实际手段和底线，不预设团圆、
  原谅或公开反击才是正确结局；
- 关键文件/录音/账目若是证据，先确定文字要清楚可读、只保留图形，还是留到后期制作，
  不能让“大家看见了”建立在不可读画面上。

## 古装奇幻与身份戏：让礼制和地位先被看见

隐藏身份要让观众觉得可信，就要先用行为和画面埋下依据。对白前可以用平行剪辑，
表现两个角色或阵营同时进行相似的礼制，再用少量而明确的画面信息表达不平等：

- 已确定的造型与佩饰用途；
- 随行者的类别/队形，而非把每个群众都扩张成个人资产；
- 谁拥有、递交或拒绝哪件身份/礼制道具；
- 到达方式、可进入区域、谁必须停在哪条界线外；
- 一个已知内情者如何压住或错开反应，而不是提前宣布答案。

身份揭示应由人物在公开场合的选择触发：例如拒绝服从、承担关系代价、使用先前建立的
权力，让旧解释失效。突然出现一位旁人报出头衔，只能传递信息，不能替代前置行为和选择。

“华丽”“破旧”“威严”都要落到当前故事职责，不把固定材质、身材、肤色或布光当
阶级或性别判断。群体调度和代表性反应见
[blocking-playbooks.md](../../short-drama-storyboard/references/blocking-playbooks.md)。

## 职场与喜剧：用流程证明能力，用反差制造笑点

职场能力揭示先从一个普通流程缺口开始：文件没归档、权限没交接、设备步骤被跳过、
现场无人愿意承担。后果可以荒诞，但因果要直：

```text
组织遗漏产生具体故障
→ 集体依据错误解释扩大问题
→ 被忽视者找出确切的文件、设备或位置
→ 按观众能看懂的顺序操作，并经过一个能核对结果的步骤
→ 设备、流程或现场恢复，别人能当场核对
→ 见证者依其职责逐个更新判断
→ 结果之后才改变角色权限或地位
```

喜剧来自整个机构的慌乱与人物克制之间的反差、被压住的反应和简短落点，不来自笑点数量。
若文件名、命令、表单字段或设备读数直接决定结果，就必须照抄。剧本、分镜和提示词都
要指向同一内容；画面看不清时，不能让同事用一句“修好了”代替证明。

失败征兆是所有同事先说主角厉害、屏幕只写“复杂代码飞速滚动”、每个旁观者重复同一
惊讶。先恢复操作链和结果，再决定是否需要反应镜。

## 身份错位喜剧：让外部任务逼身份作选择

身份互换、灵魂错位或人/非人身份喜剧需要一条不依赖设定梗的外部任务线：完成工作、
保护某人、取得物件、通过检查或离开空间。每一段先推进任务，再让当前身份限制改变做法：

- 明确谁占用哪种身体/身份，谁知道、误信或怀疑；变化写入身份状态与连续性，而不是靠对白提醒；
- 让身体能力、职业权限、语言方式或社会期待制造可执行阻力，人物必须调整策略；
- 多主体同场时先交代位置和观察关系，让观众知道误认如何成立；
- 任务取得局部结果后，身份错位才作为反应、关系后果或收尾按钮再次发力。

若删去身份设定后这一段没有欲望、阻力和结果，说明设定梗正在取代故事。身份形态的制作
约束见 [production-form-profiles.md](../../short-drama/references/production-form-profiles.md)。

## 生活流与小人物：让小目标留下真实余波

生活流不是没有戏剧运动，而是把变化控制在人物日常能承受的尺度。可从一个具体小目标
开始：修好物件、等到某人、守住摊位、还一件东西或完成一次照料。意外来客、误会或匮乏
让旧做法受阻；人物通过一个细小选择完成、放弃或重新定义目标，再以温柔反转或远景余韵
留下关系变化。

低强度不等于无因果。仍要看见物件归属、距离、去留、承诺或理解发生了什么；只是不要求
公开打脸、身份宣告或每段都升高音量。二维漫剧可以利用 hold pose、局部循环、环境声和
留白承接余韵，不要把真人爽剧的密集大特写、眼部推进和群体震惊当成提速办法。

## 开场选择：从旧办法开始付出代价处进入

不规定第几秒或必须哪种景别。比较几个入口，选择能让观众立刻追踪因果的一处：

- 人物正在使用惯常办法，异常结果让这套办法开始带来损失；
- 日常仪式出现一个会改变人物处境的小错误；
- 一个关系请求同时触碰双方不能兼得的义务；
- 已经发生的后果通过一件看得见的东西或行动再次出现；
- 观众比角色多知道一条会影响下一步的事实，或少知道一条必须追问的原因。

开场可以安静、喜剧化、亲密或激烈。通常应让观众感到压力，并看见一个还没解决的问题，
不是固定时长、台词数量、冲突音量或镜头类型。更完整的切入方法见
[serial-character-and-memory.md](serial-character-and-memory.md)。

## 钩子要接着本集结果往下走

钩子要从本集已经发生的结果继续往下走。先写“本集已经改变什么”，再选择一件尚未
解决、而且确实由这个结果引出的事：

| 本集留下的问题 | 可形成的下集压力 | 不成立的替代品 |
|---|---|---|
| 选择带来的代价 | 人物作出的选择即将要求下一项代价 | 无来源的新人物踹门 |
| 旧证据有了新解释 | 同一载体现在支持更窄/更危险的新解释 | 只喊“你竟然不知道真相” |
| 对手反制 | 对手根据主角刚暴露的策略封住路径 | 反派重复上一集威胁 |
| 代价到达 | 先前成功造成伤势、债务、关系或资源损失 | 黑屏前把结果全部藏住 |
| 谁能采取行动发生变化 | 新事实让某人能公开真相、逃离、作证、进入或拒绝 | 群众只重复惊叹 |
| 安全线或出口变化 | 安全距离、出口或可达区域发生变化 | 只把环境写得更阴暗 |

温馨落点、完整收束或无悬念结尾同样是创作者选项。连续多集使用相似的收尾方式不必自动
报错；审查者应判断它们是否改变了不同状态、是否兑现承诺，而不是数“钩子类型”。

## 提前写清制作难点

开发阶段就在候选方案旁写清主要制作负担，不要等到提示词阶段才发现：

- **状态数量**：关键道具、伤势、礼制造型、证据版本是否跨镜或跨集复用；
- **空间**：安全线、公开场合、仪式区、办公室操作点是否需要不同场景方位；
- **群体**：谁是需要反复出现的角色，谁是代表性见证者，谁只属于背景人群；
- **文字/声音**：规则、技术名称、文件或称呼要清楚可读、只保留图形、用 VO/OS，
  还是留到后期；
- **动作**：哪一段操作、仪式、保护或险情变化必须拆成清楚的镜头起止状态；
- **修订风险**：同一剧本重做时，必须比较内容覆盖、资产版本、必须照抄的文字、
  镜头起止状态与镜头分组方式，不能因为提示词变短就认定内容更准确。

这些负担帮助创作者比较方案，不决定题材优劣，也不要求实际生成媒体。

## 审查问题

1. 这个候选使用的是真实压力机制，还是只有题材名称和常见外壳？
2. 本轮升级具体改变知识、关系、权力、路线、资源、身体或代价中的哪一项？
3. 观众具体看到或听到什么？这些画面或声音能证明到哪一步？

   这些制作难点？
