# 题材版图与钩子手册

来自对不同题材完整生产链的定性案例阅读，示例均为合成改写。这些是
`craft_default`/`taste_option` 级别的压力与钩子选项，不是质量门槛（见 STY-06）：
用它们扩大候选空间，不用题材频率或市场统计替代创作者选择。

## 系列规模选择

- 先根据必要的状态台阶、创作者目标和制作负担决定系列规模，不从所谓主流集数倒推
  重复剧情。
- 相邻集靠"出去的压力 → 进入状态"精确咬合；规模越长，越依赖分集地图防止承诺漂移。

## 题材热度版图

生产数据中项目命名关键词的频次序（仅供开阔思路）：

穿越 > 重生 > 修仙 > 归来 > 赘婿 > 总裁 > 离婚/千金 > 复仇/虐恋 > 逆袭/闪婚/豪门/首富

值得注意的结构性赛道：

- **出海剧**：英文台词 + 中文舞台指示的混排生产（狼人/命定伴侣、豪门罗曼史、
  神话框架皆有）；台词语言不改变因果与格式纪律。
- **银发/家庭伦理**：退休长辈被家人苛待 → 尊严觉醒反击；代际冲突 + 经济控制权
  是压力引擎。
- **马甲文**：主角隐藏真实等级/身份，"每集小暴露、关键集大暴露"是其升级节拍器。
- **系统/副本流**：系统 VO 是合法的信息与反讽通道，但升级仍须改变故事状态（STY-03）。

## 冷开场模式（第 1 集前 30 秒）

生产中反复出现的开场策略，按"多快建立压力"排列：

1. **中局切入**：直接开在冲突压力点（对峙、决赛、讨债现场），零铺垫。最常用。
2. **反差仪式**：价值观对撞的视觉符号先行——大喜之日穿孝服，"于他大喜，于我大丧"。
3. **第一人称反讽 VO**：一句话同时立世界观、悬念与人物姿态——
   "我买了一间空仓库。可物业告诉我，这间连老鼠都养不活的空仓库，三年欠费八十万。"
4. **绝境逃亡**：生理危机先于任何解释（雪夜破窗、大雨狂奔、孕肚特写）。
5. **底层受辱 + 幽默韧性**：受辱不失姿态——馒头被踩，主角先叹"凉了就硬了"；
   喜感缓冲加深复仇期待。
6. **情感峰值直入**：认亲、重逢、诀别的眼泪高点当第一场。
7. **时代蒙太奇 VO**：商战/年代题材以行业兴衰蒙太奇建立赌注。

选择哪种是 `taste_option`；但第 1 集必须在极短时间内完成"承诺陈述"（观众知道
反复回报是什么）属于 `craft_default`（STY-10）。

## 集尾钩子分类

生产端对钩子有成熟分工（写作时由 `$short-drama-write` 执行，规划时在分集地图
预留类型与素材）：

| 类型 | 机制 | 合成示例 |
|---|---|---|
| 闯入中断 | 新威胁/新信息载体在情绪顶点进场 | 门被踹开，捕快亮出锁链 |
| 当面撞破 | 背叛现场第三者到场 | 相拥瞬间有人喊"你来了！" |
| 戏剧反讽钩 | 观众可见角色未见的绝望信号 | 反派嚣张顶点转谄媚，迎向脸色惨白的靠山 |
| 危机悬置 | 底牌已发动，结果不展示 | 能力全开，黑屏 |
| 信息炸弹 | 用 OS 抛出改写既有事实的谜题 | "他怎么会认识她？" |
| 征程展开 | 地图/目标可视化升级（男频常用） | 七颗星标熄了一颗，"才刚刚开始" |
| 毒计预告+反预告 | 反派 OS 宣计，受害者 OS 亮"我在装" | 双 OS 对切 |
| 爽点延迟 | 破坏已发生，后果留到下集 | 第一位顾客突然捂腹倒地 |

非钩子收尾同样合法（温馨定格、黑屏字幕预告"下一集·XX"），属 `taste_option`。

分集地图不必写死钩子文案，但应记录"出去的压力"能支撑哪一类钩子（STY-10）；
连续多集使用同一类钩子而无升级，是 reviewer 可引用证据的 `reviewed_invariant`
疑点（重复压力未改变状态，见 STY-03）。
