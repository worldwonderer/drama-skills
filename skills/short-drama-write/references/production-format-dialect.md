# 生产通行剧本方言与写作工艺

来自对不同短剧方言怎样流入资产与分镜的定性案例阅读，示例均为合成改写。本套件的
规范格式见 [screenplay-format.md](screenplay-format.md)；本文档服务三个场景：

1. **规范化入口**：创作者交来的现成剧本多用此方言，识别它能显著减少误映射；
2. **交付偏好**：创作者要求按行业习惯交付时的输出方言（`taste_option`）；
3. **写作工艺**：逐案验证可迁移的节拍职责、对峙压力、系统流与钩子工艺。

**与规则分级的关系**：旧稿中的拍数、字数和格式习惯只用于识别来源方言，不是新稿
质量公式。数字只有被创作者选入本项目 house profile 后才能成为验收约束；"台词在
下游逐字保留""规范化不改台词"属于既有 structural/reviewed invariant，不因方言
而放松。

核心思想：**剧本是拍摄指令，不是文学**。每一行都必须回答"摄影机拍什么"——
心理活动走 OS，世界观走字幕/VO，情绪走表演括注，不允许任何信息以
"不可拍摄的叙述"存在（SCR-03 的生产表述）。

## 一、方言语法

一集（clip）的标准结构：

```text
<集标题（钩子文案，可选但推荐）>
【场景 1：地点 - 内/外（日/夜）】
【人物：甲、乙、丙】
△ 环境陈述或空镜（景物、氛围、光线）
▲ 人物动作（主体+单一动作+受体+可见结果）
【角色名】(表演括注)：台词
…
△ 空镜：<转场画面>          ← 场景切换处补空镜转场
【场景 2：…】
```

符号分工（同一项目内恒一致）：

- `△` **只用于环境陈述与空镜**：`△红烛高燃，喜堂内一片死寂。`
- `▲` **只用于人物动作**：`▲李威一把捏住随从甲的手腕，将密奏强行抽走，随从甲手腕被拧得发红。`
- 台词行：`【角色名】(表演括注)：台词`，冒号全角，括注可省略。

兼容变体（读旧稿须识别，写新稿不用）：场景头 `N-N 地点 日/夜 内/外`、
`场：N-N`+`景：…` 双行式、`N.内 地点 光线`；动作行统一用 △ 或统一用 ▲ 且逐拍
编号（`1▲…15▲`）；台词行 `角色名（情绪）：台词`。时段槽位词表：日、夜、晨、
黄昏、傍晚、深夜、凌晨、幽暗（光线当时段用）、时间不明。
群演写法：`村民甲/乙/丙`（首选）、`员工A/B/C`、`修士若干`、`观众*N`。

### 集标题（钩子文案）

- **悬疑对仗体**：`纸人睁眼，活人藏脸`——短语对举+威胁/异象后联。
- **逆袭对比体**：`陷入创业低谷，全村坐等我破产倒闭`——前联主角
  行动+后联外界贬损，制造打脸预期。

## 二、拍（beat）的写法

**一拍 = 一个摄影机能直接拍出来的动作**。好拍四要素：主体 + 动作 + 受体 +
可见结果：

```text
▲李威双手用力，将密奏撕成碎片，碎纸片如雪花般飘落。      ← 四要素齐全
▲王怀安双手紧握扶手，指节发白，牙齿咬得咯咯作响。          ← 情绪全部转成可见生理动作
```

禁止：心理描写混入动作行（"他心想"→ 改 OS 或表演动作）；一行塞多个独立动作
（拆多拍）；形容词堆砌无动作。

**单词行当拍用**是悬疑/惊悚段落的停顿控制手法：

```text
△ 嗒。手电筒打开。
△ 光柱停住了。
△ 画面静止。
```

台词与动作按戏剧职责交替：谈判可以连续说话，只要议程、权力或关系持续变化；追逐、
搜寻或沉默对抗也可以连续无台词，只要每拍改变位置、信息、风险或选择。不要为凑比例
插入无后果动作，也不要为缩短文本删除必要的表演处理。

表演括注是**表演指令槽**，不是纯情绪槽——高频词近半是动作词（冷笑、点头、
低声、打断、挑眉、一字一顿、摆手），也可装微动作（`(上前握住她的手)`）或语音
方式（`(声音洪亮，带着回音)`、`(方言)`）。括注只保留能与本句同时完成的表演提示；
若包含独立动作、道具接触或新的状态结果，拆为独立 ▲ 拍，而不是按字数机械截断。
台词中段可插动作括号：`回国？……（抬眼看向身旁）这三百年……`（SCR-08）。

## 三、画外音系统

| 记法 | 语义 | 用法 |
|---|---|---|
| `角色（OS）：` | 当下内心独白 | 心声、内心吐槽、反讽双声道；漫剧须显式加"(口型完全闭合，严禁出现唇动)"防穿帮 |
| `角色 VO：` | 跨时空旁白/电话对面/回忆解说 | 只压缩当前行动所需前史，或承载电话另一端 |
| `规则VO：` | 系统/世界播报（当角色登记进人物行） | 系统流专用，见下 |

OS 与 VO 严格分工，同项目内记法统一。双语出海版：台词外文+中文括号对照，全剧一致。

## 四、【】指令系统

`【特写】`、`【音效：砰！砰！砰！】`、`【字幕：…】`（人名/地名/等级标注）、
`【闪回】…【闪回结束】`（本人记忆）、`【闪入：场景 内 夜】…【闪入结束】`
（他人往事插叙）、`【转场】`、`【空镜：…】`、`【卡点】/【钩子】`（集尾定格）。

**系统流多通道选项**（按 accepted text/audio profile 选择，不强制冗余）：

1. **规则VO 当角色**：人物行写 `人物：林某、规则VO`；台词行 `规则VO：奖励一，…！`
2. **光屏字幕做视觉载体**：需要观众读取且资产允许 exact-readable 时，播报后可跟
   `△光屏字幕：【…】`；no-text、纯声音或无批准承载面时不得自动补字幕。
3. **任务面板三件套**：首次曝光一次给全 `[字幕：<人名>・<系统名>][字幕：当前主线
   任务：…][字幕：任务进度：0%]`，后续只更新进度数字。

## 五、叙事工艺决策规则

1. **开场切入**：在既有压力迫使人物行动的窗口进入，并尽早让观众看见本剧承诺的
   具体载体。异常、反差奇观、关系越线或有后果的日常选择都可以承担开场；前史只给
   当前行动所需部分，不按固定拍数或 VO 句数验收。题材与钩子分类见
   [genre-and-hook-playbook.md](../../short-drama-develop/references/genre-and-hook-playbook.md)。
2. **对峙升级**：每轮应改变至少一项真实筹码、策略、距离、信息或关系位置。口头挑衅、
   道具动作、身体压迫、权力亮出与败方独处只是候选手段；是否使用、使用几级及如何
   收尾取决于人物选择和局部结果，不能机械套成固定阶梯。
3. **对白攻防回合**：每轮只做一件事（逼问/抵赖/加码/让步/反将）；谈判用逐条
   加码的条件清单；强弱互换的姿态信号——掌控局面的一方台词变短、变平静。
4. **爽点接收**：主角亮出能力或证据后，让承担权力、关系或信息后果的人做出可见
   接收。群像可以分出不同立场，也可以用一个代表性反应或全场状态变化；不按群演
   台词数量制造热闹。
5. **反派台词自我暴露**：开口即输出压迫性世界观；都市题材高级写法是**礼貌台词
   包毒**——全程客气话完成羞辱与反杀，配 OS 双声道反讽。
6. **闪回**只在过去事实会改变当前选择、理解或情绪后果时插入：前有可见触发，后有
   当前时空的处理与回收；信息量与长度由当前行动需要决定。
7. **集尾钩子四型**：新威胁进画；身份揭穿半句停（"你没死？！"）；宣战台词；
   显式 `【钩子】` 标注。悬念收口范式：静止画面 + "下一秒——" + 画外音一句话
   切黑。**末拍重叠**（可选）：强悬念边界处下一集首拍逐字重复上一集末拍。
8. **打戏**：动作写清部位、路径与物理后果；重复招式只有在空间、资源、策略或关系
   持续变化时保留。是否让主角受伤、让谁出声、何时加入新变量由本场承诺与人物代价
   决定，不按循环次数填充。
9. **拆集边界**：先兑现本集局部结果，再留下由该结果启动的决定、危险或问题。边界
   可以落在悬念顶点、关系落点或现实交接；不能只因为场景切换或目标字数到达而截断。

## 六、项目 Profile 决策（`craft_default`）

| 决策 | 如何确定 |
|---|---|
| 单集规模 | 从目标成片时长、表演语速、动作路径、停顿和转场反推；不按通用字数填充。 |
| 场景数量 | 使用完成本集目标、阻力、转向与局部结果所需的最少场景；地点变化本身不创造戏。 |
| 拍数与密度 | 每拍承担可见行动、反应、信息或状态变化；重复职责应合并，过载职责应拆分。 |
| 台词负载 | 结合说话目的、语速、口型与同时发生的动作试听；放不下时删减、拆拍或请求修订。 |
| 表演括注 | 保留能与台词同步完成的提示；独立动作与状态结果进入动作拍。 |
| VO/OS/字幕 | 只承载当前必须知道且不能由更合适的可见行动表达的信息，并服从 text/audio policy。 |

规范化旧稿时保留其已接受的 house profile；偏离任何示例数量都不能单独成为 finding。

## 七、自检清单

1. 每个动作行删掉后是否丢失一个**可拍摄画面**？（丢形容词→删对了；丢画面→写对了）
2. 有没有任何一行是摄影机拍不出来的？（心理→OS；设定→字幕/VO）
3. 开场是否已经有压力、行动或承诺载体？集尾是否先有局部结果，再产生 outgoing pressure？
4. 每轮升级是否改变筹码、策略、距离、信息或关系？承担后果的人有可见接收吗？
5. 台词、动作与反应是否都承担职责，并能在目标时长和语速内执行？
6. 抽象情绪是否已落为可表演行为、语音或选择，而不是只堆形容词？
7. 编号拍是否连号无重号？格式全集恒一致？
8. 系统流信息的声音、字幕与面板是否服从 accepted text/audio policy，且没有无来源重复？

## 八、范例

### 范例 A：对峙戏标杆（升级链：密奏→撕碎→砸脸→拔刀，败方收尾）

```text
11-1 边关监军大帐 夜/内
人物：王怀安 随从甲 李威
△油灯跳动，王怀安坐在虎皮交椅上，手指有节奏地敲击木制扶手，发出笃笃声响。
△随从甲双手捧着明黄色绢帛，躬身退后。
王怀安：本监军的密奏，三日内必须送到长安。
随从甲：大人放心，卑职这就去驿站。
△随从甲刚转过身，营帐门帘被猛地掀开，寒风灌入。
△李威身披染血战甲大步踏入，铁靴踩在地面发出沉重声响。
李威（猛然伸手）：慢着！
随从甲（身体一颤）：李，李将军？
△李威一把捏住随从甲的手腕，将密奏强行抽走，随从甲手腕被拧得发红。
李威（撕开密奏扫视）：大敌当前，监军大人还有闲心写密奏？
王怀安（脸色阴沉）：李将军，这是本监军呈给圣上的机密，你无权...
△李威双手用力，将密奏撕成碎片，碎纸片如雪花般飘落。
△李威抓起一把碎纸，重重砸向王怀安脸上。
李威（俯身逼近）：边关数万将士的命都在我手上！你再敢搞这些阴私勾当，别怪本将军不给你体面！
王怀安（身体颤抖，后退半步）：你，你敢对本监军...
李威（拔出腰刀，刀尖指向王怀安）：老子在战场上砍了二十年人头，还怕你这张嘴？
△王怀安瞳孔收缩，额头渗出汗珠。
△李威收刀入鞘，拂袖转身，大步离开，帐门帘剧烈摆动。
△王怀安双手紧握扶手，指节发白，牙齿咬得咯咯作响。
王怀安（低声，眼中闪过狠毒）：好，好得很。
```

### 范例 B：规范化最小对照（只动结构与表演层，不改台词）

原稿：

```text
△礼成后，宾客散去，苏卿润走到两人面前，拍了拍萧尘渊的肩膀。
苏卿润：好好待她。
萧尘渊：放心，我此生定不负她。
```

规范稿：

```text
▲礼成后，宾客散去，苏卿润走到两人面前，拍了拍萧尘渊的肩膀。
【苏卿润】：好好待她。
【萧尘渊】(目光坚定)：放心，我此生定不负她。
```

（变换：人物动作 △→▲；台词加【】归属；补微表演括注；台词逐字保留。）

## 九、反模式（定性案例中暴露的失效机制）

1. 小说原文直贴当剧本（含"他笑得合不拢嘴"类不可拍心理叙述）。
2. 换行破碎/全角空格污染（PDF 粘贴事故，"灰 雾 降 临"）。
3. 场景头、人物行、动作行挤成一个巨型段落。
4. 同质拍循环（同一句式 6+ 次只换受害者名词，爽感第 3 循环后衰减）。
5. 三行骨架剧本（只有"镜头/画面/台词"，无拍无场景头无括注）。
6. 编号重号/漏符号（逐拍编号应机器校验连号）。
7. 括注写成长句（>12 字拆独立拍）。

## 十、扩写工作流

生产中存在"原文 → 扩写稿"流程（如 1500 字扩到 3000 字）：扩写只加动作拍、
反应拍与微表演载体，**不加新情节、新信息或新角色**。扩写稿仍以原文为
authority；语义新增属于 owner 修订，不属于扩写。
